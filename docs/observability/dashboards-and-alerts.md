# 운영 화면·사례 조사·알림

- 현재 전환 조건·사용자 영향·비교 및 수집 신뢰도 확인
- 관측 근거에 따른 확대 중지·축소·복귀 판단 지원

## 기능 계약

| 항목 | 정의 |
| --- | --- |
| 시작 조건·입력 | 실행·비교·수집 지표, 적용 revision, 전환 이력과 허용된 이벤트 조회 |
| 결과·출력 | 현재 상태 보고·원인별 경보와 확대 중지·축소·복귀 판단의 근거 |
| 실패·제한 | 지표 누락의 정상 표시 금지, 전용 웹 콘솔·자동 승격은 초기 필수 범위 제외 |

## 최소 운영 화면 또는 보고서

- 기존 대시보드·조회 도구를 통한 아래 정보 제공
- 화면 구성과 무관하게 판단에 필요한 항목 유지

| 영역 | 반드시 보일 정보 | 가능한 판단 |
| --- | --- | --- |
| 현재 전환 | stage, 설정 비율, 실제 v2 배정·응답 분포, 설정·backend 배포 revision | 관측 조건과 혼합 배포 구간 확인 |
| 사용자 상태 | serving 오류·지연·전송 불완전·취소 | 확대 중지·serving 롤백 필요 여부 |
| 양쪽 실행 | v1/v2 및 role별 시작·종료·오류·지연·inflight | shadow 부하와 신규 API 품질 분리 |
| 비교 품질 | M·X·C와 오류·비교 불가 사유, 성공·예상 거절·혼합 쌍별 비교율 | 실제 계약 차이 조사 |
| 관측 상태 | queue depth·age, 저장 오류·유실, E/S/D/T/C/W | 증거가 충분한지 판단 |
| 데이터 문맥 | 확인 가능한 source·revision·freshness, unknown·시차 초과 분포 | 데이터 drift와 코드 차이의 구분 |
| 사례 조회 | 기간·route·result·revision으로 제한된 이벤트 검색 | 문제를 재현할 입력·계약 단서 확인 |
| 변경 이력 | 적용·롤백 시각, 이전/다음 설정, 변경 사유 | 악화 시점과 변경 연계 |

- 상세 값 저장 불가 시에도 허용된 필드 경로·오류 분류·정책·trace 요약으로 조사 가능
- 대시보드 접근 권한과 원문 표본 조회 권한의 분리
- 실시간 잠정값·마감된 구간·데이터 없음·관측 미확인 상태의 명시적 구분
- route·요청군·응답 크기별 coverage와 편향 확인

## 알림과 대응

| 신호 | 첫 대응 제안 | 추가 확인 |
| --- | --- | --- |
| serving 오류·p99 기준 초과 | 비율 확대 중지 | v2 문제인지 프록시·공유 의존 문제인지 분리 |
| shadow 오류·timeout 급증 | shadow 축소 또는 중지 | serving 자원 침범, target capacity |
| 비교 완료율 하락 | 승격 중지 | 큰 응답·문맥 부족·파싱·큐·deadline 사유 |
| 권한·테넌트 불변식 위반 | 해당 route 전환 중지와 복귀 판단 | 영향 사용자와 허용 범위의 증거 보존 |
| 저장 오류·queue age 증가 | 수집 드롭 계측, 필요 시 shadow 축소 | DB·batch·만료 작업 상태 |
| 인스턴스 revision 불일치 | 확대 중지 | 배포 실패와 전파 시간 |
| 데이터 freshness 초과·필수 문맥 누락 | 비교 신뢰도 확인과 확대 중지 | 데이터 동기화 담당 경로와 원인 분리 |
| 메트릭·수집 heartbeat 누락 | 관측 상태 미확인으로 처리 | 수집 경로·프로세스·배포 상태 |

- 숫자 임계값·연속 관측 창·담당자·통보 경로: 실제 SLO·운영 방식에 따라 확정
- 트래픽이 없는 구간의 저장 성공 0건과 수집 경로 장애 구분
- 자동 승격·자동 롤백: MVP 범위 제외
