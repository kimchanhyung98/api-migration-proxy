# 관측

사용자·backend·비교·수집 지표를 분리하고 누락을 포함한 운영 판단 근거를 제공한다.

저장된 이벤트만으로 전체 요청을 추정하지 않고, 각 처리 단계의 분모와 누락을 함께 확인한다. 차이가 관측되지 않은 상태와 충분히 비교해 일치를 확인한 상태를 구분한다.

```mermaid
flowchart LR
    A["사용자·backend 실행"] --> D["단계별 지표·분모 분리"]
    B["비교 결과·미비교 사유"] --> D
    C["수집·저장 누락"] --> D
    D --> E["성능·차이율·커버리지 해석"]
    E --> F["운영 화면·알림<br/>전환 판단 근거"]
```
