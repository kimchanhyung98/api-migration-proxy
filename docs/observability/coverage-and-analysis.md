# 비교 커버리지와 실험 분석

- 선택·실행·종료·비교·저장 단계별 분모 유지
- 성공한 일부 사례만으로 전체 전환 안전성 판정 금지

## 기능 계약

| 항목 | 정의 |
| --- | --- |
| 시작 조건·입력 | 같은 route·epoch의 E/S/D/T/C/M/X/W, 실패·유실·문맥 분류 |
| 결과·출력 | 비교 범위·조건부 차이율·저장 완료율과 데이터 없음·미확인 상태 |
| 실패·제한 | 구간 끝의 미완료와 최종 유실 구분, 예상 거절·다른 epoch·편향 표본의 혼합 방지 |

## 분모 정의

- 동일 route·관측 epoch와 요청 시작 구간을 대상으로 정의
- epoch 조건: 설정·비교 정책·backend 배포·데이터 문맥·실험 부하 조건
- 종료·저장 지연을 반영한 구간 마감 필요; 구간 끝 미완료 요청의 즉시 유실 처리 금지

| 기호 | 정의 |
| --- | --- |
| E | 전환이 활성화된 지원 route에서 효과·권한·입력 의미의 복제 적격성을 통과한 요청 수 |
| S | E 중 shadow 표본으로 선택된 요청 수 |
| D | S 중 반대편 요청이 실제 시작된 수 |
| T | D 중 양쪽 실행이 모두 종료된 수; 실패·timeout·취소 포함 |
| C | T 중 비교 조건을 만족해 `matched` 또는 `different`로 판정된 수 |
| M | C 중 `matched`인 수 |
| X | C 중 `different`인 수 |
| W | S에 해당하는 비교 이벤트 중 저장이 확인된 고유 이벤트 수 |

- 전환 비활성·지원 범위 밖·복제 부적격 요청: E 제외, 전체 요청·선택 사유 메트릭에는 유지
- 표본 선택 후 슬롯·크기·종료 제한으로 실행하지 못한 요청: S 유지, D 제외
- 관측 유실 없이 처리가 끝난 고정 구간의 관계: `E ≥ S ≥ D ≥ T ≥ C`, `C = M + X`, `0 ≤ W ≤ S`
- W: 실행 실패·비실행 이벤트도 포함 가능; C와 일렬 포함 관계 없음
- 메트릭·저장 경로 유실 시 관계 확인 불가 표시; 수치를 강제 보정하거나 미확인을 0으로 대체 금지

### 집계 출처와 시각 경계

| 집계 | 출처·갱신 지점 | 한계 |
| --- | --- | --- |
| E·S·D·T | 프록시의 적격 판정·선택·실행 시작·양쪽 종료 지점 | 이벤트 저장 성공 여부와 독립 계측, 프로세스·계측 경로 유실 가능 |
| C·M·X | 비교 판정 완료 지점 | 비교 큐 드롭 요청 제외, 상세 저장 표본에서 역산 금지 |
| W | 고유 event ID의 저장 확인 또는 저장소 고유 행 조회 | ACK 미확인·지연·보존 만료·재시도 중복의 영향 구분 |

- 런타임 counter: 각 단계 처리 시각에 증가; 같은 벽시계 구간의 counter 차이를 동일 요청 시작 집단으로 간주 금지
- 실시간 비율: 진행 중 요청·저장 지연이 포함된 잠정 관측치로 표시
- 고정 구간 검증: 시작 시점의 기존 작업과 종료 시점의 잔여 작업을 구분한 뒤 동일 요청 집단으로 집계
- 원래 요청 집단을 확인할 수 없는 경우: 정확한 분모 검증 미완료로 표시, DB에 남은 행만으로 E·S 복원 금지
- 저장 ACK 미확인: 저장 실패 확정과 구분; 동일 ID 재확인 후 W 반영
- 저장소 고유 행 조회: 해당 구간의 보존 만료 전 수행; 재시도 횟수를 저장 건수로 집계 금지
- exporter 재시작·중복 수집·프로세스 강제 종료: counter와 저장소의 불일치 원인 조사, 완전성 미확인 구간 표시
- 실제 집계 구현·허용 유실 수준: 분석 구간·허용 지연·재시작 빈도·기존 모니터링 기능을 기준으로 확정

| 지표 | 계산 | 해석 |
| --- | --- | --- |
| shadow 선택률 | S / E | 원하는 표본을 골랐는가 |
| shadow 실제 시작률 | D / S | 선택했지만 실행 못 한 요청이 얼마나 되는가 |
| 선택 표본 비교 완료율 | C / S | 선택한 비교 중 실제 판정 가능한 비율 |
| 전체 적격 비교 범위 | C / E | 복제 가능한 전체 요청 중 비교된 범위 |
| 조건부 차이율 | X / C | 비교 가능한 응답 안의 차이율 |
| 저장 완료율 | W / S | 선택 요청의 요약 기록이 얼마나 남았는가 |
| 실제 v2 배정 요청 비율 | v2 serving 배정 요청 / 전환 대상 요청 | 사용자 cohort 비율과 다를 수 있는 실제 트래픽 분포 |

- 분모 0: `데이터 없음` 표시
- 관측 누락으로 분모 미확인: `미확인` 표시; 데이터 없음과 구분
- C·M·X 내부 구분: `comparison_class=success`, `expected_rejection`, `mixed`
- 성공·예상 거절 혼합 쌍: X와 `mixed`에 포함; 성공 쌍·예상 거절 쌍 통계에 중복 포함 금지
- v2 배정 요청의 성공·실패·client 취소 분리; 성공한 사용자 응답만으로 배정 비율 계산 금지

### 분모 해석 예시

- 합성 구간: E=1,000, S=100, D=95, T=95, C=80, M=76, X=4, W=90
- 선택률 10%, 실제 시작률 95%, 선택 표본 비교 완료율 80%, 전체 적격 비교 범위 8%
- 조건부 차이율 5%, 저장 완료율 90%
- “95% 일치하므로 전환 가능”이라는 결론 금지
- 비교 미완료 20건의 구성: 미실행 5건과 실행 후 판정 불가 15건
- 저장 미확인 10건: 앞선 20건과 겹칠 수 있으므로 합산하여 유실 30건으로 해석 금지
- W·C의 차이 원인과 미완료·유실·ACK 미확인 상태를 각각 조사

## 실험 해석

- 동일 요청의 계약 비교·실사용자 canary·용량 및 캐시 검증을 별도 실험으로 구분
- 비율·설정·backend 배포·비교 정책 변경 시 epoch 분리 및 합산 한계 표시
- 알려진 데이터 drift: source·freshness 문맥과 함께 분류; 불일치를 전부 데이터 시차로 제외 금지
- shadow의 공유 DB·cache·외부 quota 사용에 따른 v1 사용자 영향 확인
- route·사전 정의한 요청군·응답 크기 구간별 coverage 확인; 큰 응답·느린 요청의 선택적 누락 감시
- 사용자 전환율·구매·검색 만족도: 기존 서비스 계측 연결 가능, 프록시 HTTP 지표로 대체 불가
- 전체 v2 단계: 동시 v1 사용자 대조군 부재, 이후 변화를 모두 마이그레이션 효과로 귀속 금지
