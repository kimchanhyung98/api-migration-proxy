# API Migration Proxy 공통 용어

- 범위: API 전환 도메인에서 사용하는 공통 용어
- 실행 방식·운영 수치: 해당 기능 문서에서 별도 정의

## 용어

- **v1 / v2**: 마이그레이션의 기존·신규 API 백엔드; 공개 URL 버전·개별 배포 리비전과 별개의 이름
- 혼동 주의: 문서별 old/new 혼용

- **Serving**: 한 요청에서 사용자 응답을 제공하도록 선택된 백엔드 역할; v1 또는 v2에 배정 가능
- 혼동 주의: 항상 v1인 primary로 해석

- **Shadow**: 같은 논리 요청을 실행하되 사용자 응답으로 선택되지 않은 반대편 백엔드 역할
- 혼동 주의: 항상 v2인 candidate, 응답 없는 단순 로그 복사

- **Route**: 같은 method·경로 의미와 공개 계약을 공유하는 등록 API 단위
- 혼동 주의: 개별 raw URL

- **Cohort**: 같은 기준으로 serving 버전에 배정되는 사용자·세션·테넌트 등의 집합
- 혼동 주의: 사용자 배정 비율과 실제 QPS 비율의 동일시

- **Cohort group**: serving 배정의 일관성을 공유해야 하는 연관 route 집합
- 혼동 주의: 독립적인 모든 API를 한 집단으로 간주

- **Logical request**: 호출자가 프록시에 보낸 요청 한 건; 양쪽 실행 여부와 독립적인 단위
- 혼동 주의: backend 호출 수

- **Backend attempt**: 하나의 논리 요청을 처리하기 위한 특정 백엔드의 실행 한 번
- 혼동 주의: 논리 요청 수와 동일시

- **Comparison event**: 하나의 논리 요청에 대한 양쪽 실행 결과·비교 판정·문맥을 묶은 관측 기록
- 혼동 주의: 성공한 응답만의 로그

- **Configuration revision**: 요청의 목적지·배정·실행·수집 정책을 식별하는 설정 스냅샷 버전
- 혼동 주의: 백엔드 배포 버전

- **Comparison policy revision**: 비교 대상·허용 차이·제외 규칙의 의미를 식별하는 정책 버전
- 혼동 주의: 설정 revision과 항상 같은 버전으로 해석

- **Stage**: 기준선·shadow·canary·전체 전환·종료 등 마이그레이션의 운영 단계
- 혼동 주의: 단순 배포 완료 상태

- **Epoch**: 같은 설정과 관측 조건으로 결과를 해석하는 구간
- 혼동 주의: 서로 다른 revision의 무조건적 합산

- **Fallback**: 개별 요청 실패에 대응해 다른 백엔드에서 사용자 응답을 얻으려는 동작
- 혼동 주의: 전체 전환의 rollback

- **Rollback**: 이후 요청의 serving 배정을 이전 운영 상태로 되돌리는 변경
- 혼동 주의: 데이터 복구까지 완료된 상태
