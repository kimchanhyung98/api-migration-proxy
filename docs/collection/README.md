# 데이터 수집

비교 이벤트를 제한된 방식으로 적재하고 상세 표본·조회·보존을 관리한다.

결과 요약을 기본으로 수집하고, 상세 데이터는 허용된 필드와 표본에 한해 마스킹한다. 적재 실패와 저장 확인 불가를 구분하며, 수집 경로가 사용자 응답을 지연시키지 않도록 상한을 둔다.

```mermaid
flowchart LR
    A["결과 요약"] --> C["상한이 있는 큐"]
    B["선택된 상세 표본<br/>허용 필드·마스킹"] --> C
    C --> D["배치 적재·중복 방지"]
    D --> E["권한 내 조회·만료 정리"]
    C -. "수집 한계" .-> F["유실·저장 확인 불가 계측"]
    D -. "저장 실패·응답 불명" .-> F
```
