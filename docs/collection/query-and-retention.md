# 이벤트 조회와 보존 기간 관리

- 제한된 범위의 비교 사례 조회
- 목적별 보존 기간이 지난 데이터 정리

## 기능 계약

| 항목 | 정의 |
| --- | --- |
| 시작 조건·입력 | 기간·route·result·revision·event ID 조회 조건, 조회 권한, 요약·상세·이력 보존 정책 |
| 결과·출력 | 허용된 이벤트 조회 결과와 만료 정리 상태 |
| 실패·제한 | 무제한 export·전체 body 인덱싱 제외, 만료 삭제 실패·적체 관측 |

## 조회와 보존

- 최소 검색 조건: 기간·route·result·reason·backend 역할·설정 및 비교 revision·event ID
- 조회 제공 방식: 기존 도구·제한된 SQL·내부 조회, 전용 웹 콘솔은 필수 범위 제외
- 조회 권한·행 및 기간 상한·export 범위·원문 보존 여부 명시
- 요약·상세·전환 이력의 목적별 보존 기간 분리
- 보존 기한 연장 시 용량·조회·삭제 비용 재확인
- 무제한 JSON 저장·전체 body 인덱싱·별도 검색 클러스터는 초기 구성 제외
- 조회 범위와 예상 적재량에 맞춘 기간·route·결과·revision 인덱스 검토; 물리 설계는 저장소 결정 후 확정

## 조회 시나리오

| 조사 목적 | 최소 필터 | 결과에서 확인할 것 |
| --- | --- | --- |
| 신규 버전의 값 차이 | 기간·route·different | 비교 정책·차이 경로·양쪽 상태 |
| 특정 적용 이후 실패 | configuration revision·backend 배포 revision·오류 이유 | backend 역할·실행 지연·관측 epoch |
| 한 요청의 양쪽 결과 | event ID 또는 검증된 trace 상관관계 | serving 선택·입력 문맥·결과·저장 시각 |
| 수집 한계 조사 | not_comparable·reason·기간 | 캡처 상한·파싱·데이터 문맥 |

- 상세 권한 미보유 시 요약만 제공
- 상세 미선택·저장 실패·만료 상태 구분, 빈 원문 정상 수집 표현 금지
- 저장 이벤트 조회 결과를 전체 E·S 분모로 해석 금지
- 요약보다 상세가 오래 남는 고아 데이터 방지; 별도 보존 근거가 없는 경우 상세 먼저 삭제
- 만료 작업의 반복 실행·중단 후 재개 시 동일 범위 안전 처리
- 조회·삭제 batch와 범위 상한: 저장소 선택 뒤 실제 적재량으로 검증
