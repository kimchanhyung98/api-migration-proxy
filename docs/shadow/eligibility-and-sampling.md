# 복제 적격성 판단과 표본 선택

- 목적: 반대편 실행 허용 여부 판정 및 사용자 응답 배정과 독립적인 shadow 표본 선택

## 기능 계약

| 항목 | 정의 |
| --- | --- |
| 시작 조건·입력 | route의 실제 효과·권한·데이터 계약, 전환 활성 여부, shadow 표본율 |
| 결과·출력 | ineligible·sampled_out·selected의 선택 결과와 사유 |
| 실패·제한 | 부작용 미확인 경로의 복제 금지; selected와 실제 전송 완료 구분 |

## 세 가지 비율

| 이름 | 적용 대상 | 의미 |
| --- | --- | --- |
| `v2_serve_ratio` | 전환이 활성화된 route의 배정 단위 | v2 serving에 배정할 bucket 비율 |
| `shadow_sample_ratio` | 복제 가능한 각 요청 | 반대편 backend 실행을 선택할 확률 |
| `detail_sample_ratio` | 상세 수집이 허용된 비교 이벤트 | 마스킹된 상세 표본을 저장할 확률 |

- 유효 비율: 0~1; 초기 제안값은 모두 0
- shadow 선택: serving cohort와 다른 난수 또는 별도 salt 사용; 특정 serving 집단만 비교되는 편향 방지
- 상세 표본 선택: 실행·비교 여부에 영향 없음
- MVP의 비교 CPU 표본율: 별도 도입 제외
- 비교 처리: 수집 가능한 양쪽 결과 비교; CPU 예산 초과 시 비교 누락과 원인 명시
- full shadow·별도 비교 표본 운영: 추가 제어·분모가 필요한 추후 검토 항목

## 적격성 판정 순서

1. 전환이 활성화된 지원 route 확인
2. 동일 요청의 DB·외부 서비스·quota 효과 검토; GET 여부만으로 복제 허용 금지
3. 양쪽 권한·테넌트·입력 의미 확인
4. 부작용·복제 범위 검증 요청을 E에 포함
5. 독립적인 shadow 표본으로 선택한 요청을 S에 포함; 자원 한도로 미실행한 요청도 S에 유지

## 경계 사례

- v2 serving: 반대편 v1이 shadow 역할 수행
- 비율 1: 적격 요청 전체의 선택 의미; 실행 슬롯·입력 상한·취소로 실제 실행량 감소 가능
- 양쪽 실행: 운영 cache·DB·외부 quota 영향 가능; 관측·용량 판단에 해당 제약 포함
- 복제 적격성 변경: 변경 이후 요청의 E·S와 설정 revision 구분; 과거 실험 조건과 혼합 금지

## 요구사항과 수용 조건

| ID | 우선순위 | 요구사항 | 수용 조건 |
| --- | --- | --- | --- |
| FR-09 | P0 | 실제 효과에 따른 shadow eligibility 정의 | 등록만으로 복제하지 않으며 부작용 미확인 경로는 shadow 불가 |
| FR-10 | P0 | shadow 표본율을 serving 비율과 독립 설정 | v2 serving에서는 v1이 shadow; 표본율 1의 적격 요청은 실행 제한·취소가 없을 때 양쪽 각각 한 번 실행, 미실행 사유·분모 유지 |
