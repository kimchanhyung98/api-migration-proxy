# API Migration Proxy 기획

제품과 기능의 책임별 기획, 공통 기준과 기술 자료를 정리한다.

사용자 응답은 미리 선택한 serving에서 반환하고, 조건을 충족한 요청만 반대편 shadow도 실행한다. 비교·수집 결과와 운영 지표를 근거로 v2 전환 비율을 조정한다.

```mermaid
flowchart LR
    A["API 요청"] --> B["경로·serving 선택"]
    B --> C["serving 실행"] --> D["사용자 응답"]
    B -. "적격성·표본·상한 충족" .-> E["반대편 shadow 실행"]
    C --> F["선택된 요청의 종료 후<br/>비동기 비교·수집"]
    D --> F
    E --> F
    F --> G["관측·수동 전환 판단"]
    G -. "후속 요청에 적용" .-> B
```
